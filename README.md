# AnalisisMercadoApp
## Descripción
Esta aplicación busca ayudar en la recolección de datos correspondientes a las variables de estudio
(de acuerdo al análisis de mercado que se desea realizar) y el procesamiento y obtención de información de estas.   
El proyecto está principalmente desarrollado en Java Spring Boot y Thymeleaf, siendo esta una aplicación SSR 
(Server-Side Rendering).
## Objetivos 
- Implementar una aplicación utilizando buenas prácticas de desarrollo.
- Organizar el código mediante una arquitectura clara y sencilla.
- Aplicar los conocimientos de Java y Spring Boot en un proyecto práctico.
## Tecnologías utilizadas
- Java: 21
- Spring Boot: 4.1.1
- thymeleaf: motor de plantillas para aplicaciones web con Java.
- Maven: gestión de dependencias y construcción del proyecto.
- PostgreSQL: motor de base de datos.
- Git: control de versiones.
- GitHub: alojamiento del repositorio.
## Requisitos previos
- JDK compatible con la versión de Java del proyecto.
- Git.
- Acceso a una terminal.
